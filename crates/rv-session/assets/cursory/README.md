# Recorded cursor trajectories

Source: https://github.com/JWriter20/cursory-js/tree/ee9621a9ce9dcb798ecd3d298e80ac301b3feb96
Original recordings: https://github.com/Vinyzu/cursory
License: LGPL-3.0-or-later; see LICENSE and UPSTREAM-NOTICE.

The compressed database is copied unchanged. RV uses these recordings for explicit
single-gesture input testing; its Rust adapter selects and transforms recordings
and preserves their sample times. It is not a parity port of Cursory's complete
noise, selection and resampling algorithms, and mouse recordings do not establish
human finger behavior or any third-party acceptance result.
