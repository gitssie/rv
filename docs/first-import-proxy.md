# 首次同步的代理选择

刷新手机备份先保存目录及有效 IDFV 卡片。对 Vinted 尚无完整 state 的账号，已有代理绑定则继续读取；未绑定则整批进入「选择店铺代理」Dialog，统一选择一个已保存代理。确认时以 SQLite 事务填补绑定，保留并发已保存的绑定，再从原手机读取完整 state 并初始化任务。

取消、Esc 或关闭 Dialog 不读取 state；目录记录保留，下次刷新继续配置。没有代理时取消并在设置→代理新增，随后刷新。确认时代理已删除或店铺已删除／归档则拒绝整批提交。断线时仅保存绑定，下次连接原手机刷新继续读取。多个来源批次排队确认。

后续刷新不自动改绑，也不会按地区或负载自动分配。共享密码 Session 代理仍由运行时为各店铺创建独立 Session；选择同一代理不保证公网 IP 不同。
