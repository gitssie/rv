# RV 主界面：已确认设计

当前生效主图：[rv-home-v4.png](rv-home-v4.png)。用户已确认此版，旧版草稿不作为实现依据。

2026-10-15 样式规范更新：上述设计图继续约束信息布局；控件外观统一使用当前 GPUI Component 默认主题。Home、控制窗口、文件传输、Apple/App 环境和助手共享主题与文字密度，仅远程画布背景保持深色。主题只定制 RV 主色及正文约13px、辅助约11px、等宽12px；控件圆角、选中、悬停、禁用与焦点由组件管理。公共组合位于 `crates/rv-app/src/ui.rs`，颜色和尺寸策略位于 `theme.rs`；不按图片逐个覆盖按钮外观。

一级/二级工具页面共用工具面板容器与8px边距。简单确认沿用 AlertDialog；确认后持续显示进度的任务使用共享紧凑 Dialog。静态检查命令为 `python3 scripts/check-ui-style.py`，CI 同步执行。此轮完成主机检查及编译，视觉验收由用户执行。

- 顶部是可扩展的全局工具栏，没有“首页”导航 tab。
- 左侧是独立滚动的手机列表，不显示“手机”文字标题；显示名称、型号、系统版本和连接状态。
- 设备记录使用本地 `id` 作主键；完整真实 GUID 用于唯一识别设备，不在界面显示，不以 IP 地址代替。
- 主区域是统一卡片布局，没有“虚拟 App”文字标题；搜索、筛选属于内容区。
- 数据存于 RV 本地 SQLite。统一字段包含多标签和文本备注；业务特色信息用文本保存，并通过全文检索查找。
- 根据 App Bundle ID 选择渲染策略。普通 App 展示环境/备份；Vinted 展示店铺及业务信息。
- 虚拟 App 主键直接使用真实 IDFV，重复同步只关联已有记录。卡片只来源于真机 ZXTouch App 备份，不提供文件导入或手工创建；图中的“导入/新建”不能按文件导入或手工建卡实现。
- 手机连接状态与店铺会话、后台任务状态分别展示；业务对象不绑定死在一台手机或一份备份上。

图中账户、设备、业务状态和工具栏动作均为示例，不代表已实现或真机状态。
用户已提供开发规范，详见 [AGENTS.md](../../AGENTS.md)：新版采用 SQLite，不兼容旧设备配置；密码也存入 SQLite，并保留本地加密；按模块、插件和策略模式实现通用及个性化 UI；有疑问及时询问用户。

## Vinted 店铺浮层（已确认）

店铺卡片及浮层以 [rv-vinted-shop-v3.png](rv-vinted-shop-v3.png) 为依据，原首页布局保持 v4。首页显示最近一条本地商品记录；无商品记录时，以骨架保留商品图片、标题、价格与状态的布局，不显示虚构业务内容。仅点击 App 头像打开宽 450px 的紧凑浮层。已配置标签单独一行，以标签图标加标签显示；卡片不显示备份数量。会话和未读状态使用图标及悬停提示保留。商品、订单切换使用 Lucide 图标，数量以 badge 显示；空列表以四行骨架保留浮层结构。手动同步和定时开关在同一行，无搜索或分页控件，超出空间时滚动。账号读取、会话检测、备份与备注放在更多操作中。

商品布尔状态仅明确为 true 才显示 badge，各状态并列。不可交易由明确的 transaction_permitted=false 推导，延迟发布由 item_alert_type=delayed_publication 推导；缺失、null、false 或字符串 true 不作为肯定状态。关闭不能表示已售出。

展示图片统一保存于 RV 数据目录 business-images，按完整图片 URL 的 SHA256 复用。首页与浮层仅使用本地文件；并发窗口和进程以文件锁避免重复下载，验证后原子发布，重启沿用缓存。下载失败保留占位图，下次读取可重试，不影响业务记录入库。

## 统一聊天中心（已确认）

以 [rv-unified-chat-v1.png](rv-unified-chat-v1.png) 为视觉依据。顶部工具栏进入 980×620px 双栏浮层；左侧按账号筛选、未读筛选，右侧消息、商品上下文与输入区。输入区复用当前 gpui-component 官方 textarea chat 示例，Enter 提交、Shift+Enter 换行。

聊天存储与 Bundle HTTP 策略放在 rv-business/chat，个性化展示策略放在 rv-app/app/chat/plugins。会话按 App IDFV＋平台会话 ID、消息按本地会话＋平台消息 ID 去重；联系人按账号隔离。未接入的 App 不展示虚构会话。RV 开启期间每 60 秒同步注册账号，打开浮层和手动刷新也可同步；不补跑关闭期间周期。

当前实现 Vinted 新版 messaging/main 的游标会话列表、消息详情、文字回复和显式标为已读。获取详情不隐式标为已读；服务端 allow_reply=false 或系统对方只读。图片沿用共享本地缓存，上传链路未核对前不显示上传操作。陌生消息类型保留原始业务 JSON，显示可识别内容或占位。

草稿持久化，发送先保存 outbox 再请求；超时、断线、异常成功响应或 5xx 保留未知状态，不自动重发。2xx 只表示已提交，回读确认平台消息 ID 后消除待确认记录；无法确认时由用户核对后清除本地记录。

测试使用本地 HTTP 模拟服务。研究资料的真实只读样本已确认系统通知；普通会话、真实发送与已读写入尚未在真实账号验证。
