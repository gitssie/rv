# 店铺 IP 检测

店铺面板 Globe 图标打开原生 Popover，每次打开查询 `https://ipwho.is/?fields=success,message,ip,country,region,city`，展示 IP、Country、Region、City 的原始字符串，不做翻译。加载和失败均在弹出层显示；关闭、切换店铺后的旧结果不会覆盖新查询。

请求必须绑定店铺代理，复用本店铺业务使用的完整前置→出口线路及共享密码 Session；未绑定时报错，不直连。通过独立排他租约与包括同店铺在内的业务和换 IP 互斥，不触发换 IP、不改变上次业务店铺或代理配置、不写 IP 历史。HTTP 超时10秒，响应最大16KiB，不携带 Vinted 凭据。

面板保留资料刷新、消息、未读统计、手机来源的手动 Token 获取、头像设置及双向交接。商品/订单刷新继续位于各自 Tab。手动备份同步和状态修复入口均已移除，首次自动导入保留。
